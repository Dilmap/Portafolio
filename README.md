## `// 00 SISTEMA`

Portafolio personal con estética **retro-futurista**: monitor CRT, campo de estrellas y una órbita de tecnologías alrededor de mi retrato en pixel art. Construido desde cero con HTML, CSS y JavaScript puro, sin frameworks ni librerías.

```text
> base ......... La Guajira, Colombia
> estado ....... ONLINE
```

## `// 01 CARACTERÍSTICAS`

| Módulo | Qué hace |
|---|---|
| **Órbita de tecnologías** | Tres anillos giratorios (el grande dorado, el mediano verde y el pequeño blanco). Al pasar el cursor sobre un ícono aparece el nombre de la tecnología con un color aleatorio entre dorado, verde y blanco. |
| **Campo de estrellas** | Fondo en `canvas` con estrellas que titilan y flotan. |
| **Efecto CRT global** | Scanlines en toda la página y una banda de tracking VHS que desciende lentamente. |
| **Rol que se escribe solo** | Efecto de terminal que alterna mis perfiles profesionales. |
| **Stack con LEDs** | Barras de LED que se encienden al hacer scroll; dorado = lo que más domino. |
| **Ruta de trayectoria** | Línea de tiempo que se dibuja con el scroll y activa cada etapa. |
| **Contacto interactivo** | Filas con relleno dorado al pasar el cursor y copiado de email con un clic. |
| **Bilingüe ES / EN** | Cambio de idioma instantáneo cargado desde archivos JSON. |
| **Reloj en vivo** | Hora de Colombia en el pie de página. |

## `// 02 DISEÑO`

- **Paleta:** azul noche `#0B1220` · dorado `#D4AF37` · verde fósforo `#4ADE80`
- **Tipografías:** Josefin Sans (títulos y texto) · VT323 (terminal) · JetBrains Mono (etiquetas)
- **Escala fluida:** todo el tamaño se basa en `rem` con un tamaño raíz adaptable, así se ve bien desde un celular hasta un monitor o TV.
- **Accesibilidad:** foco visible con teclado, contraste alto y respeto a `prefers-reduced-motion` (se desactivan las animaciones si el usuario lo pide).
- **Rendimiento:** las animaciones usan solo `transform` y `opacity`.

## `// 04 EJECUTAR EN LOCAL`

```bash
# 1. Clonar el repositorio
git clone https://github.com/Dilmap/Portafolio.git
cd Portafolio

# 2. Abrir con un servidor local (necesario para el cambio de idioma)
#    Opción A: extensión "Live Server" de VS Code
#    Opción B:
python -m http.server 8000
```

Luego abre `http://localhost:8000`.

> **Nota:** el cambio de idioma usa `fetch` para leer los JSON, por eso no funciona abriendo `index.html` directamente desde el disco. En GitHub Pages funciona sin problema.
